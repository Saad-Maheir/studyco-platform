# StudyCo — دليل تشغيل وتحديث المنصة التعليمية

أهلاً بك! هذا الملف يشرح لك بأسلوب بسيط وواضح كيفية التعامل مع موقع **StudyCo**، وتحديث أي معلومات فيه، ورفعه على استضافة **Hostinger** أو **Vercel** خطوة بخطوة.

---

## 🚀 ١. كيفية تغيير رقم الواتساب (سريعة وفي مكان واحد)

تمت برمجة رقم الواتساب داخل **ملف واحد مركزي فقط** في المشروع بأكمله، وذلك لضمان سهولة تعديله بضغط زر واحدة مستقبلاً.

1. افتح الملف التالي:
   ```
   assets/js/config.js
   ```
2. ستجد السطر التالي في البداية:
   ```javascript
   whatsappNumber: "+6281311322022",
   ```
3. قم بتغيير الرقم المكتوب بين التنصيصين إلى رقمك الجديد بالرمز الدولي (مثال: `+966500000000` أو `+628123456789`).
4. احفظ الملف. سيتحدث رابط الواتساب في جميع أزرار الموقع تلقائياً وفي كل اللغات!

---

## 🌐 ٢. كيفية تعديل أو ترجمة أي نص في أي لغة

جميع نصوص الموقع مخزنة داخل مجلد `locales` كملفات JSON لكل لغة:

- `locales/id.json` (الإندونيسية - الافتراضية)
- `locales/ar.json` (العربية)
- `locales/en.json` (الإنكليزية)
- `locales/ko.json` (الكورية)
- `locales/ja.json` (اليابانية)
- `locales/zh.json` (الصينية)
- `locales/ru.json` (الروسية)
- `locales/fr.json` (الفرنسية)
- `locales/es.json` (الإسبانية)

للتعديل: افتح ملف اللغة المطلوبة وعدّل القيمة النصية المقابلة للمفتاح.

---

## 📊 ٣. كيفية تحديث أرقام الإحصائيات

لتغيير أرقام شريط الإحصائيات (مثل 500+ جامعة شريكة أو 10,000+ طالب):

1. افتح ملف `index.html`.
2. ابحث عن القسم المسمى `stats-bar-section`.
3. ستجد الخاصية `data-target="500"` قم بتغيير الرقم `500` للرقم الذي تريده وسيتم عدّه تلقائياً على الشاشة.

---

## ☁️ ٤. كيفية رفع الموقع على استضافة Hostinger خطوة بخطوة

الموقع مصمم كملفات ثابتة 100% (Static Site) تعمل مباشرة على أي استضافة:

1. قم بضغط جميع ملفات جذر المشروع (`index.html`, `.htaccess`, مجلد `assets`, مجلد `locales`, مجلد `data`) في ملف مضغوط بصيغة `.zip`.
2. ادخل إلى لوحة تحكم **Hostinger hPanel**.
3. اختر **File Manager** (مدير الملفات) وافتح مجلد `public_html`.
4. قم برفع ملف الـ Zip واعمل له **Extract** (فك الضغط) داخل `public_html`.
5. افتح رابط موقعك في المتصفح، وسيشتغل الموقع فوراً بسرعة فائقة ودعم كامل للغات وRTL!

---

## ⚡ ٥. المعاينة والرفع على Vercel

1. اسحب مجلد المشروع كاملاً وأفلته في حسابك على **Vercel Dashboard**.
2. اضغط **Deploy**.
3. سيعطيك Vercel رابط معاينة مباشر للموقع فوراً.
